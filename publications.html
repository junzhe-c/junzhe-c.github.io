Persistent Object Narratives for Token-Efficient Video Language Models

Junzhe Chen, Siyuan Meng, Xiaojie Guo

arXiv preprint, 2026

SlotNarrative links recurring object observations through a lightweight, parameter-free memory, then represents each object with identity and state tokens. It provides a compact interface of 144 allocated visual-token positions for a frozen Video-LLM, independent of the number of sampled frames.

Paper / PDF / BibTeX

TOC-Bench: A Temporal Object Consistency Benchmark for Video Large Language Models

Junzhe Chen, Siyuan Meng, Yuxi Chen, Man Zhao, Wenyao Gui, Xiaojie Guo

arXiv preprint, 2026

TOC-Bench evaluates whether Video-LLMs preserve object identity, state, and temporal continuity through occlusion, disappearance, reappearance, and interactions. It contains 2,323 human-verified questions over 1,951 videos, covering 10 diagnostic dimensions with object-track-grounded evidence.

Semi-RSTOD: Toward Semi-Supervised Remote Sensing Tiny Object Detection

Wenhao Xiang, Qianying Tang, Junzhe Chen, Xiang Wei, Shunli Zhang, Li Zhang

Journal of Electronic Imaging, 34(3), 033047, 2025

This work studies semi-supervised tiny-object detection in remote-sensing imagery, bringing together visual recognition, small-scale targets, and learning from limited annotations.

Adaptive Quantization with Mixed-Precision Based on Low-Cost Proxy

Junzhe Chen, Qiao Yang, Senmao Tian, Shunli Zhang

IEEE International Conference on Acoustics, Speech and Signal Processing (ICASSP), pp. 6720–6724, 2024

LCPAQ combines hardware-aware profiling, Hessian-based sensitivity analysis, and Pareto selection for mixed-precision quantization. Integer programming and a low-cost proxy search help select layer-wise quantization settings for resource-constrained deployment.
